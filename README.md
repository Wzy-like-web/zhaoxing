# 我的小馆 · 商家自用堂食点餐（v4 一桌多号版）

商家自用的堂食收银/点餐小程序。**永久零成本**，所有数据保存手机本地。

## v4 改动亮点（适配小吃店/拼桌场景）

- ✅ **大按钮选品**：进点菜页就是 2 列大按钮，点一下弹配料层
- ✅ **预设配料**：每个菜品自己的可选配料（加葱花/双倍肉/不要辣 etc.）
- ✅ **预设备注**：全店通用备注标签（少盐/打包/加急 etc.），一键勾选
- ✅ **自定义备注**：除预设外可手打一行
- ✅ **一桌多号**：同一桌可以坐多拨人，每拨独立账单
- ✅ **流水号**：今日全店递增（1号、2号...），方便喊号
- ✅ **出单页**：下单后直接展示大字号小票，可截图发后厨
- ✅ **打印接口预留**：等你买了蓝牙打印机即可启用

## 流程

```
桌位首页
  ├── 点空闲桌 → 点菜（新一号）
  └── 点忙碌桌 → 桌位详情
        ├── 看每一号点了啥
        ├── 给某号继续加菜
        ├── 给某号结账
        └── 同桌新一拨人 = 新建一号
```

## 使用步骤

### 1. 准备小程序
[微信公众平台](https://mp.weixin.qq.com/) 注册个人主体小程序（免费）

### 2. 开发者工具打开
- 项目目录：本目录
- AppID：填你的
- **不勾选**「使用云服务」

### 3. 改一处配置
`project.config.json` 里的 `appid` 改成你的

### 4. 跑起来
- 模拟器编译
- 首次启动自动写入示例数据：6 个菜品（羊杂汤/羊肉粉/牛肉面/凉皮/茶叶蛋/可乐）+ 6 张桌 + 6 个预设备注
- 顶部「预览」生成体验版二维码（永久有效）

## 操作流程演示

### 来客人点单
1. 桌位首页 → 点「3号桌」（绿色空闲）
2. 进入点菜页（2 列大按钮）
3. 点「羊杂汤」 → 弹层
4. 勾「加葱花」「加香菜」「双倍肉」 → 选「少盐」 → 输入「老人吃，软一点」
5. 点「加入订单」
6. 继续点「可乐」（无配料的菜，弹层只有备注）
7. 点底部「下单出单」
8. 跳到出单页 → 看大字号小票 → 截图发后厨群（或后续接打印机自动出）
9. 「完成」回到首页，3号桌变红色

### 同桌又来一拨陌生人
1. 桌位首页 → 点「3号桌」（红色，显示已有 1 拨）
2. 进桌位详情 → 看到 1号 在用餐
3. 点底部「+ 同桌新一拨人」
4. 进入点菜（新一号）
5. 选完下单 → 现在 3 号桌有 1号、2号 两拨人

### 结账
1. 桌位首页 → 点「3号桌」 → 桌位详情
2. 找到 1号 → 点「结账」
3. 选支付方式、改实收金额（可打折）
4. 确认 → 1 号释放，3号桌还有 2号 在用餐
5. 等 2号 也结账 → 3号桌变回绿色空闲

### 加菜（同一拨人加）
1. 桌位首页 → 点「3号桌」 → 桌位详情
2. 找到 1号 → 点「继续加菜」
3. 进入点菜页（标题：3号桌·1号 加菜）
4. 选菜下单 → 合并到 1 号的清单里

## 设置页能干啥

- **预设备注管理**：增删全店通用备注（如新增"加冰""不放醋"）
- **数据备份**：导出 JSON 到剪贴板/微信文件助手
- **数据恢复**：从微信聊天文件选择 JSON 备份
- **清空重置**：恢复出厂示例数据

## 数据结构

```javascript
// 桌位（极简）
table: { _id, name }

// 菜品
dish: {
  _id, name, price, category,
  addons: [{ name: '加葱花', price: 0 }, ...]
}

// 订单/号
ticket: {
  _id, number,           // 今日第几号（全店流水）
  dayKey: '2026-05-21',  // 用于按日重置号码
  tableId, tableName,
  items: [{
    dishId, name, price, count,
    addons: [{name, price}],
    notes: ['少盐'],
    customNote: '老人吃，软一点'
  }],
  totalAmount, actualAmount, payMethod,
  status: 'open' | 'paid' | 'cancelled',
  openedAt, paidAt, updatedAt
}

// 预设备注（全店通用）
presetNotes: ['少盐', '不要葱', '打包', ...]
```

## 打印机接入（待你买打印机后启用）

`pages/print/print.js` 里的 `onPrint()` 当前是占位实现。

接入流程：
1. 买蓝牙小票打印机（推荐：佳博 GP-58MB III，¥150~180）
2. 设置页加「连接打印机」入口
3. 实现 `utils/printer.js`：`wx.openBluetoothAdapter` + ESC/POS 指令
4. `print.js` 的 `onPrint()` 调用 printer 模块

打印小票样式（已设计好，看 print.wxml 即视感）：
```

  +双倍肉
  ※少盐
  ※老人吃，软一点
----------------
可乐         ×1
================
2026-05-21 15:35   ¥31
```

## 数据备份建议

每天闭店：
1. 设置 → 导出数据 → 保存为文件
2. 微信文件传输助手发送
3. 留底备查

恢复：
1. 设置 → 恢复数据 → 从聊天文件选择
2. 选你之前发的 JSON
3. 确认恢复
